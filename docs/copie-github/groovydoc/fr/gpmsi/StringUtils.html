        • public static final java.lang.String normalizeCode(java.lang.String str)

          Normalisation de chaîne de caractère générale. Si null, retourne chaîne vide. Sinon, retourne la chaîne sans les espaces de début et de fin, et transformée en majuscules. Utile pour les codes en général (GHM, etc), sauf pour la CIM10 où il faut en plus enlever les points.

          Parameters:
          str - La chaîne à normaliser
          Returns:
          La chaîne normalisée

        • public static final java.lang.String normalizeLineSeparators(java.lang.String str, java.lang.String lsep)

          Normaliser pour que toutes les fin de lignes (\r seul, \n seul, ou \r\n) soient remplacées par le lsep donné. Utile pour les comparaisons de chaînes de caractères, qui peuvent échouer juste parce que les fins de ligne sont différentes.
          Si on veut le séparateur système utiliser System.lineSeparator() pour lsep.
          Exemple 1 : remplacer les séparateurs de ligne par "\n" (séparateur Unix) : normalizeNewLines(str, "\n").
          Exemple 2 : remplacer les séparateurs de ligne par "\r\n" (séparateur Windows) : normalizeNewLines(str, "\r\n").
          Exemple 3 : remplacer les séparateurs de ligne par le séparateur par défaut de la plateforme : normalizeNewLines(str, System.lineSeparator()).

          Parameters:
          str - la String en entrée
          lsep - la String à mettre en séparateur de ligne
          Returns:
          la string normalisée
