Outils intégrés

Introduction

Depuis Gpmsi 2.1.8 il y a la possibilité d'appeler directement une application java (donc une classe qui a une méthode main(String[]) ).

Cela se fait via la commande runjava de la façon suivante :

%GPMSI_BASE%\v2.1\scripts\runjava  [ arguments ]

Un certain nombre de librairies possèdent ainsi des commandes intégrées, voici plusieurs exemples.

H2 Console

La base H2 permet de lancer une console qui s'ouvre dans le navigateur local, que l'on peut démarrer de la façon suivante :

cd C:\Local\CCAM\v78\dbf
%GPMSI_BASE%\v2.1\scripts\runjava org.h2.tools.Console

Par contre cette console tourne en permanence, pour l'arrêter il faut faire CTRL-C dans la fenêtre de ligne de commande.

H2 Backup

La base H2 a une commande de backup qui permet de faire une sauvegarde en SQL d'une base. Si on lance cette commande depuis le répertoire qui contient la base, et qu'il n'y a qu'une seule base H2 dans le répertoire, la commande fait la sauvegarde dans le fichier backup.zip dans ce même répertoire. Ex :

cd C:\Local\CCAM\v78\dbf
%GPMSI_BASE%\v2.1\scripts\runjava org.h2.tools.Backup

Restore

La commande Restore de la base H2 restaure une base de données H2 d'après son backup. Ex :

cd C:\Local\CCAM\v78\dbf
%GPMSI_BASE%\v2.1\scripts\runjava org.h2.tools.Restore

Autres outils de la base H2

La base H2 est livrée avec de nombreux autres outils que l'on peut utiliser en ligne de commande.

Il y a :
ChangeFileEncryption, CompressTool, ConvertTraceFile, CreateCluster, Csv, DeleteDbFiles, DirectRecover, GUIConsole, MultiDimension, Recover, RunScript, Script, Server, Shell, Upgrade

Voir pour plus d'informations : https://www.h2database.com/javadoc/org/h2/tools/package-summary.html

Phonex

La classe Phonex peut être utilisée pour une recherche phonétique, en transformant un texte en français en une écriture phonétique, qui rapproche les mots de prononciation similaire. On peut l'utiliser également en commande, pour voir comment est représentée une chaîne particulière.

Ex : 
cd C:\Local\CCAM\v78\dbf
%GPMSI_BASE%\v2.1\scripts\runjava fr.gpmsi.Phonex

Utilisation :
Phonex  
Algorithmes possibles : P phonex, E phonex sans espaces, S phonex apres standardisation

%GPMSI_BASE%\v2.1\scripts\runjava fr.gpmsi.Phonex P jean

GE1

%GPMSI_BASE%\v2.1\scripts\runjava fr.gpmsi.Phonex P jean-paul

GE1-TOL

%GPMSI_BASE%\v2.1\scripts\runjava fr.gpmsi.Phonex P jeanpaul

GE1TOL

%GPMSI_BASE%\v2.1\scripts\runjava fr.gpmsi.Phonex S jean-paul

GE1TOL

%GPMSI_BASE%\v2.1\scripts\runjava fr.gpmsi.Phonex S "jean paul"

GE1TOL
